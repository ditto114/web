# MapleStory Worlds PPSN Finder

이 저장소에는 MapleStory Worlds 친구 코드(5글자)를 이용해 해당 사용자의 PPSN을
탐색하는 Python 스크립트가 포함되어 있습니다.

## 준비물

* Python 3.9 이상 (Windows 환경 권장)
* 인터넷 연결

추가 외부 패키지는 필요하지 않으며, 표준 라이브러리만으로 동작합니다.

## 사용 방법

1. 명령 프롬프트(또는 PowerShell)에서 저장소 디렉터리로 이동합니다.
2. 다음 명령을 실행하여 대상 친구 코드의 PPSN을 조회합니다.

   ```bash
   python maple_ppsn_finder.py <친구코드>
   ```

   예:

   ```bash
   python maple_ppsn_finder.py kJimR
   ```

3. 스크립트가 자동으로 친구 목록을 탐색하여 PPSN을 찾아 출력합니다.

### 옵션

* `--delay <초>`: 친구 목록 페이지를 순차적으로 요청할 때 사용할 대기 시간(초 단위)입니다.
  기본값은 0.5초이며, 요청 간격을 늘려 서버 부하를 줄일 수 있습니다.

## 동작 방식 요약

1. 입력한 친구 코드의 프로필 페이지에서 노출된 친구들을 수집합니다.
2. 해당 친구들의 "전체 친구 목록" 페이지를 페이지 단위로 탐색합니다.
3. 목록에서 목표 친구 코드를 발견하면 연결된 PPSN을 출력합니다.

네트워크 상태나 MapleStory Worlds 서버 정책에 따라 일부 요청이 차단될 수 있으며,
그 경우 스크립트는 오류 메시지를 출력하고 종료합니다.
